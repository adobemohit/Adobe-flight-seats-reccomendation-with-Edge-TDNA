3. Considers seat characteristics (Exit row, Bulkhead, Zones)

## Slide 6: Smart Algorithm

**Title:** 🧮 Smart Algorithm

**Seat Selection Process:**

1. **Check User Preference**
   - Uses saved WINDOW/AISLE preference if available

2. **Price-Based Filtering**
   - Finds highest/lowest priced seat sections

3. **Seat Collection**
   - Collects available window and aisle seats

4. **Distribution Calculation**
   - 70% window, 30% aisle when available
   - Dynamic adjustment based on availability

5. **Highlighting**
   - Highlights window seats first
   - Then highlights aisle seats
   - Maximum 5 seats total
