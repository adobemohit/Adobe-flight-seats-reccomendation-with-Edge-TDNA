🎯 Overview

  1. Check Edge Profile Data - Retrieves user's last booking seat preferences from Adobe Experience Platform (AEP) Edge profile data
  2. Fetch Seat Characteristics - Determines preferred seat type (Aisle or Window) based on user's historical booking data
  3. Intelligent Seat Selection - If user data is not available, uses intelligent algorithms with 70/30 Window/Aisle distribution
  4. Price-Based Selection - Analyzes strike-through prices to identify premium seat sections (Exit row, Bulkhead, Zones)
  5. Minimum Recommendations - Recommends minimum 5 seats (configurable) based on client requirements
  6. Smart Distribution - Uses permutation and combination logic to avoid recommending seats on a single row, checks seat availability and ensures seats are not already filled

🧮 Smart Algorithm

Seat Selection Process:

  1. Check User Preference - Uses saved WINDOW/AISLE preference if available
  2. Price-Based Filtering - Finds highest/lowest priced seat sections
  3. Seat Collection - Collects available window and aisle seats
  4. Distribution Calculation - 70% window, 30% aisle when available
  5. Highlighting - Highlights window seats first, then aisle seats
